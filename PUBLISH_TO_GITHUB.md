# Publish to GitHub

This repository is already configured with:

- Remote: `https://github.com/yashumani/where-it-happened.git`
- Branch: `main`
- Initial commit: `83f184a Initial free website MVP`

## macOS, Linux, or Git Bash

Open a terminal in this folder and run:

```bash
git push -u origin main
```

GitHub may ask you to sign in through your browser or use a personal access token.

## Windows PowerShell

Open PowerShell in this folder and run:

```powershell
git push -u origin main
```

## After the push

Confirm the following files appear in `yashumani/where-it-happened`:

- `index.html`
- `styles.css`
- `app.js`
- `cities.js`
- `README.md`
- `.github/workflows/pages.yml`
